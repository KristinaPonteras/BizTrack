# BizTrack Simple Redesign — Product Categories

This ZIP contains the simple light redesign source folder and an expanded sample product catalogue.

## Product categories
- Beverages
- Snacks
- Canned Goods
- Instant Foods
- Personal Care
- Household Supplies
- School Supplies

The catalogue contains 37 sample products with unique SKUs, sample cost and selling prices in PHP, stock quantities, and reorder levels.

## Important
The CSV is a reference catalogue only. It does not automatically insert records into the live database. Create the categories and products using your existing BizTrack Categories and Products pages, or use an import feature if your project already has one.

All prices and stock quantities are sample values for a school project. Adjust them to match your chosen business.

## Installation
1. Back up your current `frontend/src` folder.
2. Extract this ZIP.
3. Replace your current `frontend/src` with the included `src` folder.
4. Run `npm run build` from the `frontend` directory.
5. Test locally before deploying.

Keep your existing backend, database credentials, and environment variables unchanged.
